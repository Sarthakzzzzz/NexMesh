# NexMesh

This repository contains a local NVIDIA FLARE federated-learning proof of
concept for MNIST.

## Verified

- Three client datasets are generated by a seeded split.
- Each client receives a separate 20,000-sample dataset.
- The client datasets have no pairwise image overlap.
- FedAvg is configured for three clients and five rounds.
- Client pods can train with CUDA on an NVIDIA GeForce RTX 5050.
- Kubernetes exposes three logical GPU slots through time-slicing.

Raw client datasets are mounted only at their corresponding client pods. The
server test split is separate and is mounted only at the server.

## Main Files

- `jobs/fedavg_nn/job.py` - NVFlare FedAvg job definition.
- `jobs/fedavg_nn/train.py` - client-side PyTorch training.
- `jobs/fedavg_nn/server_evaluator.py` - server evaluation component.
- `workspace/fedlearn/split_mnist.py` - deterministic dataset generation.
- `kind-config.yaml` - local Kind node and mount template.
- `k8s/` - Kubernetes deployment manifests.
- `commands.md` - setup, deployment, verification, and cleanup commands.

the Kind configuration.

## Current Limitation

Five-round client GPU training has completed successfully. Server-side
per-round evaluation artifacts have not yet been verified in the live NVFlare
deployment.
